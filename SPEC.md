# ZAMICORE System Specification (v0.1-draft)
Deterministic State-Vector Storage & Inference Architecture

## 1. System Invariants (Базовые принципы)
1. Vector Anchor Over Token History: Контекст диалога редуцируется до единичного вектора скрытого состояния h ∈ S^(d-1) вместо конкатенации KV-кэша.
2. Zero-VRAM Contamination: Видеопамять освобождается после генерации ответа. Нет накопления истории — нет семантического дрейфа и энтропии внимания.
3. Deterministic Tunneling: Вектор инжектируется напрямую в срез слоев (экватор). При смене темы — холодный чистый старт без старых токенов.

---

## 2. Hardware & Storage Layout (ZFS & NVMe)

### 2.1 Dataset Parameters (FreeBSD ZFS)
* Root Dataset: zroot/zamicore
* Attractors Dataset (реестр долговременных якорей):
  - recordsize = 8k (ровно float16[4096] = 8192 байта)
  - compression = off (энтропия нормализованных тензоров ~ белый шум)
  - atime = off (ликвидация паразитного I/O на запись)
  - primarycache = all (принудительное удержание в ARC/ОЗУ)
  - secondarycache = all (L2ARC на быстром NVMe)
  - sync = standard, logbias = latency
* Scratchpad Dataset (оперативный кольцевой буфер кинетики):
  - sync = disabled (скорость системной памяти, обход ZIL)
  - redundant_metadata = most

### 2.2 Hierarchical Memory Mapping (4KB Alignment)
* Physical Page Size: 4096 байт (аппаратный сектор NVMe).
* Micro-Routing Density: 32 бассейна на 1 страницу ZFS (128 байт/бассейн: низкоранговые проекции d_sub=64 в fp16).
* I/O Guarantee: One-Shot 4 KB read per routing step.

---

## 3. Math & Vector Engine (AVX-512 SIMD)

### 3.1 Dimensions & Types
* Dimension (d_model): 4096 (для моделей 7B/8B) или 8192 (для 70B).
* Precision: float16 для хранения на диске (8 КБ), float32 в регистрах AVX-512 (zmm0-zmm31).
* Constraints: Строгое выравнивание в памяти по 64 байтам (aligned_alloc(64, ...)).
* Dependency Policy: Zero external math libraries (BLAS/LAPACK free).

### 3.2 State Transitions
 Внутриканьонный сдвиг (NLERP):

  h_{t+1} = normalize((1 - α) * h_t + α * u)

 Детекция бифуркации (смена темы):
  - Условие: cos(h_t, u) < THRESHOLD_BIFURCATION (default: ~0.35)
  - Действие: h_t коммитится в снапшот ZFS, VRAM очищается, u становится новым корнем h_0.
  - Разрешение парадоксов (Saddle Points):
  - Метод: Gentlest Ascent Dynamics (GAD) на единичной гиперсфере.
  - Поведение: Заморозка перевала в узел BIFURCATION_SADDLE или ортогональный импульс e_orth (синтез).

---

## 4. Tensor Injection Pipeline

### 4.1 Layer Cut-Off (Экватор)
* Точка среза (L_eq): ~60-65% глубины модели (слои 21-24 для 32-слойной архитектуры).
* Процедура калибровки: Индивидуальный эмпирический замер дисперсии скрытых состояний.
* Пропуск прямого прохода: 65% ранних слоев исключаются из инференса при попадании в каньон.

### 4.2 Cross-Attention as Disk Navigation

* Macro-Routing: α_trunk = softmax( (h * C_trunks^T) / sqrt(d) )
* Meso-Routing:  α_branch = softmax( (h * C_branches^T) / sqrt(d) )
* Micro-Routing: α_basin = softmax( (h * C_page32^T) / sqrt(d) ) [Single 4KB Page]
* Сложность выборки: O(log N) от объема сохраненных знаний.

### 4.3 Two-Phase Inference Execution Model (Двухфазный контур инференса)

Инференс входящей реплики физически разделен на две изолированные фазы с промежуточным синхронным арбитражем на стороне ядра хоста.

## 1. System Invariants & Core Manifesto (Фундаментальные принципы)

### 1.1 Три базовых принципа архитектуры
1. **Точка вместо цепочки токенов (Vector Anchor Over Token History):**  
   Контекст диалога редуцируется до векторной координаты скрытого состояния $\vec{h} \in \mathcal{S}^{d-1}$ на единичной гиперсфере. Долговременная память хранится в виде дискретных геометрических аттракторов, а не раздувающегося KV-кэша.
2. **Нулевая энтропия VRAM (Zero-VRAM Contamination):**  
   После завершения шага генерации память ускорителя полностью очищается ($KV_{\text{past}} = \emptyset$). Отсутствие накопления истории ликвидирует семантический дрейф, паразитную гравитацию старых токенов и деградацию внимания.
3. **Детерминированный волновод и независимый старт (Deterministic Tunneling):**  
   Вход в сформированный контекст осуществляется через мгновенную инжекцию вектора в терминальные слои. Новая тема стартует на чистой карте без вычислительных задержек и интерференции с прошлыми сессиями.

### 1.2 Терминологический базис
* **Бассейн притяжения (Attractor Basin):** Глобальная многомерная воронка потенциального рельефа, стягивающая векторы к единой макро-теме (предметной области).
* **Каньон (Canyon / Stream):** Локальный желоб минимальной энергии внутри бассейна, задающий естественную траекторию развития связного диалога.
* **Седловина (Saddle Point):** Критическая точка первого порядка ($\nabla V = 0$, $\lambda_1 < 0$, $\lambda_{2\dots d} > 0$) на границе двух бассейнов или каньонов. Точка ветвления, логического парадокса или альтернативного выбора.
* **Страт / Корж (Interaction Stratum):** Неделимый квант взаимодействия: триада $(q_k, a_k, \vec{h}_k)$, где $q_k$ — запрос, $a_k$ — ответ модели, а $\vec{h}_k$ — их замкнутый барицентр.
* **Шлюз инжекции (Canyon Ingress Point):** Аппаратный/программный срез сети на слое $L_{\text{eq}}$, через который вектор состояния подменяет тензор активаций, минуя стандартный прогон внимания.

* **Commit:** Страт $\mathcal{S}_k = \{ \vec{h}_k, \text{parent\_hash}, \text{artifact\_ref}, \text{timestamp} \}$.
* **Diff:** Векторное смещение $\Delta \vec{h} = \vec{h}_k - \vec{h}_{k-1}$.
* **Tree/Blob:** Хранилище артефактов в ZFS (`store`), куда складывается актуальный монолит кода без загрязнения контекста инференса.
* **Checkout:** Считывание 4KB дескриптора нужного коммита и прямая инжекция вектора $\vec{h}_{\text{target}}$ в шлюз $L_{\text{eq}}$ (задержка: одно обращение к NVMe/ARC).
* **Merge:** Поиск седловой точки между расходящимися ветками через GAD.

## 3. Two-Phase Inference & Ingress Pipeline

### 3.1 Схема двухфазного инференса

```text
[ N новых токенов ] (KV-кэш = 0)
         │
         ▼
  [ ФАЗА 1: Слои 0 ──► L_eq ] ─────────► Вектор импульса u
                                                │
                                                ▼
                                    [ АРБИТРАЖ ХОСТА (OS) ]
                                    det(G(q_1, a_1, u)) ≈ 0 ?
                                        │               │
                                    ДА  │               │ НЕТ (Бифуркация)
                                        ▼               ▼
                        NLERP(h_anchor, u)       Коммит старого h_anchor;
                                        │        u -> новый корень h_0
                                        ▼               │
  [ ФАЗА 2: Слои L_eq+1 ──► L_max ] ◄───┴───────────────┘
         │  (Шлюз инжекции / Волновод)
         ▼
  [ Буферизация вывода ] ──► [ Отчуждение артефакта кода ] ──► [ Ответ пользователю ]

```

### 3.2 Фаза 1: Съем импульса намерения (Impulse Extraction)

* **Диапазон:** Слои $0 \to L_{\text{eq}}$ (первые $\approx 60\text{--}65\%$ глубины сети; слои 0–21 для 32-слойной модели).
* **Вход:** Исключительно токены текущей входящей реплики ($N_{\text{new}} \ll N_{\text{history}}$).
* **Состояние памяти:** Чистая VRAM, отсутствие исторических KV-пар.
* **Выход:** Нормализованный вектор $\vec{u} \in \mathcal{S}^{d-1}$ на выходе слоя $L_{\text{eq}}$.

### 3.3 Промежуточный арбитраж ядра (Kernel Arbiter)

На стороне FreeBSD CPU вычисляется матрица Грама для проверки копланарности нового импульса относительно предыдущего страта $(q_{k-1}, a_{k-1})$:

$$G = \begin{pmatrix} 
q_{k-1} \cdot q_{k-1} & q_{k-1} \cdot a_{k-1} & q_{k-1} \cdot u \\
a_{k-1} \cdot q_{k-1} & a_{k-1} \cdot a_{k-1} & a_{k-1} \cdot u \\
u \cdot q_{k-1} & u \cdot a_{k-1} & u \cdot u
\end{pmatrix}$$

* **Связность ($\det(G) < \varepsilon_{\text{coplanar}}$ и $u \cdot a_{k-1} \ge \tau_{\text{canyon}}$):**
Импульс признается движением по текущему каньону. Формируется координата инжекции через сферическую интерполяцию:

$$\vec{h}_{\text{injected}} = \text{normalize}\left((1 - \alpha)\vec{h}_{k-1} + \alpha \vec{u}\right)$$


* **Бифуркация / Смена темы ($\det(G) \ge \varepsilon_{\text{coplanar}}$):**
Предыдущий страт коммитится в ZFS. Вектор $\vec{u}$ становится корнем новой стопки: $\vec{h}_{\text{injected}} = \vec{u}$.

### 3.4 Фаза 2: Шлюз инжекции и волновод (Waveguide Rollout)

* **Диапазон:** Слои $L_{\text{eq}} + 1 \to L_{\text{total}}$ (терминальные $\approx 35\text{--}40\%$ слоев сети).
* **Механизм шлюза:** Входной тензор активаций слоя $L_{\text{eq}} + 1$ принудительно перезаписывается вектором $\vec{h}_{\text{injected}}$.
* **Поведение волновода:** Верхние слои работают без обращения к истории, разворачивая детерминированный вектор в текст и локальные патчи кода.

## 4. Mathematical Engine (AVX-512 Kernel)

### 4.1 Формирование диполя страта (Барицентр шага)

Для каждого шага $k$ вектор вопроса $\vec{q}_k$ и вектор сформированного ответа $\vec{a}_k$ стягиваются в единый гравитационный центр шага:

$$\vec{h}_k = \text{normalize}\left(\frac{\vec{q}_k + \vec{a}_k}{2}\right)$$

### 4.2 Поиск седловых точек (Gentlest Ascent Dynamics)

При столкновении двух взаимоисключающих аттракторов $\vec{h}_A$ и $\vec{h}_B$ система запускает алгоритм GAD на процессоре для поиска седловины перевала:

$$\vec{v}_{\parallel} = \text{normalize}(\vec{h}_B - \vec{h}_A)$$

Вдоль оси реакции градиент потенциала инвертируется, по ортогональным осям сохраняется минимизация:

$$\vec{F}_{\text{gad}} = -\left(\nabla V(\vec{h}) - 2 \left(\nabla V(\vec{h}) \cdot \vec{v}_{\parallel}\right) \vec{v}_{\parallel}\right)$$

Проекция на касательное пространство единичной сферы $T_{\vec{h}}(\mathcal{S}^{d-1})$:

$$\vec{F}_{\text{tangent}} = \vec{F}_{\text{gad}} - \left(\vec{F}_{\text{gad}} \cdot \vec{h}\right)\vec{h}$$

$$\vec{h}^{(t+1)} = \text{normalize}\left(\vec{h}^{(t)} + \gamma \vec{F}_{\text{tangent}}\right)$$

Критерий сходимости: $\lVert \vec{F}_{\text{tangent}} \rVert < 10^{-5}$.

## 5. Large-Scale Document Analysis (Потоковая стратификация)

### 5.1 Изоляция VRAM при анализе сверхдлинных контекстов

Анализ документов объема 200+ страниц реализуется без загрузки монолитного текста в видеопамять:

1. Потоковая нарезка документа на фрагменты по 512 токенов.
2. Прогон через слои $0 \to L_{\text{eq}}$ с мгновенным сбросом VRAM.
3. Генерация массива из $M$ стратов ($M \approx 200\text{--}400$), занимающих $1.5\text{--}3$ МБ в ZFS.

### 5.2 Подпространства сущностей и предикатов

Вектор страта факторизуется на ортогональные компоненты:

$$\vec{h}_k = \vec{e}_{\text{entity}} + \vec{p}_{\text{predicate}}, \quad \vec{e} \perp \vec{p}$$

* **Сходство объектов:** $\cos(\vec{e}_i, \vec{e}_j) \ge \tau_{\text{entity}}$ (оба страта описывают одну сущность).
* **Детекция расхождения:** Вычисление нормы разностного вектора предикатов:

$$\Delta \vec{p}_{ij} = \vec{p}_j - \vec{p}_i$$



Если $\lVert \Delta \vec{p}_{ij} \rVert > \tau_{\text{conflict}}$, пара $(i, j)$ помечается как логическая нестыковка.

### 5.3 Точечная разрядка противоречия (Zero-Waste Synthesis)

1. Вычисление седловой точки $\vec{h}_{\text{saddle}} = \text{GAD}(\vec{h}_i, \vec{h}_j)$.
2. Точечное чтение из ZFS только фрагментов $i$ и $j$ по смещениям `offset/length` ($\approx 200$ байт суммарно).
3. Инжекция $\vec{h}_{\text{saddle}}$ в шлюз $L_{\text{eq}} + 1$ и подача двух цитат в декодер. Вывод вердикта расхождения без пересчета исходных 200 страниц.

## 6. C-Structure: Дескриптор страта (4096 байт)

Каждый корж выравнивается строго по 4096 байт (физический сектор накопителя):

```c
#include <stdint.h>

#define ZAMICORE_DIM 4096
#define STRATUM_PAGE_SIZE 4096

/*
 * Заголовок дескриптора страта (64 байта, выравнивание по кэш-линии)
 */
typedef struct __attribute__((aligned(64))) {
    uint64_t stratum_id;            /* Порядковый номер коржа в DAG */
    uint64_t parent_stratum_id;     /* Ссылка на родительский корж */
    uint64_t timestamp_ns;          /* Временная метка коммита */
    uint32_t flags;                 /* Флаги: IS_SADDLE, HAS_CODE, BIFURCATION */
    uint32_t payload_size;          /* Размер связанного текста/кода */
    uint64_t payload_zfs_offset;    /* Смещение полезной нагрузки в zroot/store */
    float    coplanarity_metric;    /* det(G) текущего симплекса */
    float    energy_potential;      /* Глубина каньона V(h) */
    uint8_t  sha256_artifact[32];   /* Хэш актуального состояния кода */
} stratum_header_t;

/*
 * Полный страт (4096 байт)
 * Хранит квантованный fp16 вектор барицентра (8192 байт разбиты на 2x4KB страницы
 * либо сжаты через Random Projection / FP8 до 2048-3584 байт внутри страницы).
 */
typedef struct __attribute__((aligned(STRATUM_PAGE_SIZE))) {
    stratum_header_t header;                                     /* 64 байта */
    uint8_t          reserved[192];                              /* Дополнение до 256 байт */
    uint16_t         barycenter_fp16[ZAMICORE_DIM / 2];          /* 3840 байт: сжатое ядро вектора */
} stratum_record_t;

_Static_assert(sizeof(stratum_record_t) == STRATUM_PAGE_SIZE, "Stratum page size must be exactly 4096 bytes");
