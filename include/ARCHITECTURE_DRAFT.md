
# ZAMICORE: Черновая архитектурная спецификация (Working Draft)

## 1. Концептуальная модель: Двухтактная геометрия пространства

Система отказывается от хранения контекста в виде разрастающегося текстового окна и KV-кэша. Контекст заменяется **координатной навигацией в скрытом пространстве модели (Latent Manifold)**.

```
       [ Входные токены ]
               │
               ▼  (Такт 1: Сжатие / Воронка)
   [ Первые слои: 0 ──► L_eq ]
               │
               ▼
   ╔═════════════════════════════════════════════╗
   ║  ТОЧКА РЕПЛИКАЦИИ / ШЛЮЗ ИНЖЕКЦИИ (L_eq)    ║ ◄──► [ OpenZFS: 4KB Strata ]
   ║  Дно бассейна / Стационарный аттрактор       ║      (Координатный якорь)
   ╚═════════════════════════════════════════════╝
               │
               ▼  (Такт 2: Разворачивание / Резонанс)
   [ Верхние слои: L_eq+1 ──► L_max ]
               │
               ▼
       [ Выходные токены ]

```

### Принципы рельефа

* **Потенциальный рельеф:** Пространство весов представляет собой топографию долин (бассейнов притяжения). Каждая устойчивая тема — это долина.
* **Антиградиент как русло:** Направление наискорейшего спуска ведет со склонов бассейна прямо к его минимуму.
* **Аттрактор (Дно бассейна):** Точка равновесия на дне желоба ($\nabla V = 0$), в которой векторный долг закрыт, а смысл спрессован в стационарный вектор состояния $\vec{h}$.
* **Двухтактный цикл:**
1. *Такт сжатия:* Входные токены скатываются по склонам первых слоев ($0 \to L_{\text{eq}}$) и формируют импульс намерения $\vec{u}$.
2. *Такт разворачивания:* Верхние слои ($L_{\text{eq}}+1 \to L_{\text{max}}$) работают как распаковщик, превращающий зафиксированное на дне состояние в выходную цепочку токенов.

## 2. Арбитраж тем на срезе $L_{\text{eq}}$ (Стрелочный перевод)

На срезе слоя $L_{\text{eq}}$ конвейер делает паузу для векторного арбитража на CPU (AVX-512) перед запуском верхних слоев.

Вычисляется косинусное сходство между свежим импульсом запроса $\vec{u}$ и текущим аттрактором темы $\vec{h}_{\text{old}}$, поднятым из ZFS:

$$\cos \theta = \frac{\vec{h}_{\text{old}} \cdot \vec{u}}{\lVert \vec{h}_{\text{old}} \rVert \, \lVert \vec{u} \rVert}$$

* **Режим импульса ($\cos \theta \ge 0.6$):**
Новый запрос лежит в русле текущей темы. Вектор модифицируется добавкой:

$$\vec{h}_{\text{injected}} = \operatorname{normalize}(\vec{h}_{\text{old}} + \alpha \vec{u})$$



Результирующий вектор инжектируется в шину слоя $L_{\text{eq}}$, верхние слои продолжают движение по колее.
* **Режим бифуркации / Смена темы ($\cos \theta < 0.3$):**
Запрос ортогонален текущему контексту.
1. Текущая стопка стратов фиксируется и закрывается.
2. Инжекция блокируется: верхние слои выполняют свободный проход от вектора $\vec{u}$.
3. Ответ порождает новый независимый аттрактор; в ZFS открывается новая параллельная ветка.


* **Возврат к контексту:**
При несовпадении с активной веткой ядро сканирует заголовки верхушек всех стопок в ZFS ARC. При обнаружении резонанса ($\cos \theta \ge 0.6$) соответствующая ветка мгновенно монтируется как активная.

## 3. Механика разворачивания и защелка останова (EOS)

### Разрядка кинетической энергии

Вектор инжекции обладает конечным запасом упругой энергии (векторным долгом). На каждом шаге авторегрессии:

1. Вектор скрытого состояния проецируется на матрицу детокенизатора $W_U$ ($4096 \times N_{\text{vocab}}$).
2. Выпавший токен смещает баланс системы вперед и вниз по желобу.
3. По мере выдачи слов смысловое напряжение между вопросом и ответом падает: амплитуда смысловых проекций неуклонно снижается.

### Геометрический фиксатор (Точка кроссовера)

* Вектор токена завершения `<end_of_text>` (EOS) направлен по оси симметрии покоя ($\nabla V = 0$).
* **Кроссовер:** В момент, когда мысль грамматически и логически завершена, смысловые логиты падают ниже нуля, а проекция на вектор EOS резко возрастает.
* При $T=0$ операция $\operatorname{argmax}$ безальтернативно выбирает EOS.
* **Защита от зацикливания:** Движение назад вверх по желобу энергетически запрещено весами модели, а отсутствие старого текстового буфера исключает резонансное самоэхо.

## 4. Слой хранения: 4KB Strata на OpenZFS (FreeBSD)

Контекст материализуется в виде последовательности неизменяемых (append-only) 4-килобайтных срезов на пуле ZFS.

### Настройки датасета

```bash
zfs set recordsize=4k zroot/zamicore/strata
zfs set compression=off zroot/zamicore/strata
zfs set atime=off zroot/zamicore/strata

```

### Спецификация структуры страта (`zamicore_stratum_t`)

Размер структуры строго равен **4096 байтам** (1 сектор NVMe).

| Смещение | Размер | Поле | Назначение |
| --- | --- | --- | --- |
| `0x0000` | 4 B | `magic` | Идентификатор формата: `0x5A414D49` (`"ZAMI"`) |
| `0x0004` | 2 B | `version` | Версия формата (текущая: `1`) |
| `0x0006` | 2 B | `flags` | Служебные флаги состояния/типа бассейна |
| `0x0008` | 8 B | `stratum_id` | Монотонно растущий индекс коржа в стопке |
| `0x0010` | 32 B | `parent_hash` | SHA-256 хеш родительского страта (цепочка состояний) |
| `0x0030` | 4 B | `quant_scale` | Множитель обратного масштабирования FP32 |
| `0x0034` | 4 B | `vector_dim` | Число активных координат (фиксировано: `4032`) |
| `0x0038` | 4 B | `header_crc32` | Аппаратный CRC32 первых 56 байт заголовка |
| `0x003C` | 4 B | `reserved` | Байт-паддинг до границы 64 байт |
| `0x0040` | 4032 B | `coords` | Симметрично квантованные координаты (INT8 / FP8) |

### Квантование и I/O

* 4032 координаты упаковываются через `_mm512_cvtsepi32_epi8` с аппаратным насыщением в диапазон $[-127, 127]$.
* Запись осуществляется атомарно через `pwrite(2)` со смещением `stratum_id * 4096`.
* Доступ на чтение организуется через `mmap` без копирования данных ядра в пространство пользователя.

## 5. Аппаратный детерминизм вычислений

Для воспроизводимости траекторий «байт-в-байт» устраняется недетерминизм параллельных сумматоров и плавающей точки:

1. **Режим генерации:** $T = 0 \implies \operatorname{argmax}$.
2. **Флаги компиляции Clang (FreeBSD):**
```makefile
CFLAGS += -O3 -fno-fast-math -fno-associative-math -ffp-contract=off -frounding-math

```


*Запрет слияния умножения и сложения в FMA (`-ffp-contract=off`) исключает расхождение мантисс.*
3. **Регистр процессора `MXCSR`:**
* Принудительное включение `FTZ` (Flush-To-Zero) и `DAZ` (Denormals-Are-Zero).
* Округление: `Round-to-Nearest-Even` (IEEE 754).


4. **Симметричная редукция:**
* Любые свертки векторов $4096 \to 1$ на AVX-512 выполняются исключительно через строгое 12-уровневое бинарное дерево попарного сложения (деление массива пополам на каждом шаге).
