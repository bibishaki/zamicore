Фреймворк для исследования внутренних траекторий рассуждения авторегрессионных языковых моделей (LLM) в процессе генерации программного кода. Проект реализует пошаговый перехват скрытых состояний, онлайн-кластеризацию со сжатием истории, построение графов переходов, триангуляцию симплициальных комплексов и анализ топологического гомеоморфизма режимов генерации.

## 📌 Основные концепции и математический аппарат

В процессе генерации токенов модель проходит через последовательность внутренних когнитивных состояний. Эксперимент RRE отслеживает эти состояния в пространстве активаций и проверяет гипотезу о топологической инвариантности траекторий успешного рассуждения.

```
       Forward Pass (Слои L, Токены T)
                     │
                     ▼
       Экстракция направлений (v, u) ──► Нормировка pi_t
                     │
                     ▼
       Онлайн-кластеризация (OnlineKMeans + Log-гистограммы)
                     │
                     ▼
       Метрики пути (S_t, d_path) ──► Относительное доминирование k*(t)
                     │
                     ▼
       Цепочка переходов E ──► Фильтрация шума phi ──► Ядро порядка E_core
                     │
                     ▼
       Симплициальный комплекс K(E_core) [0-, 1-, 2-симплексы]
                     │
                     ▼
       Попарный гомеоморфизм Stab_top ──► Накопленная устойчивость Sigma(h)
                     │
                     ▼
       Изолированное тестирование assert ──► Метрика pass@1

```

### 1. Пространство представлений

На каждом шаге генерации $t$ по скрытым состояниям блоков $l = 1, \dots, L$ вычисляются векторные поля направлений:

* **Смещение по контексту (токену):**

$$v_{t,l} = \frac{h_{t,l} - h_{t-1,l}}{\Vert{}h_{t,l} - h_{t-1,l}\Vert{}}$$


* **Смещение по глубине (слоям):**

$$u_{t,l} = \frac{h_{t,l+1} - h_{t,l}}{\Vert{}h_{t,l+1} - h_{t,l}\Vert{}}$$


* **Единое нормированное представление шага $\pi_t \in S^{d-1}$:**

$$\pi_t = \frac{\sum_{l} v_{t,l} + \sum_{l} u_{t,l}}{\left\Vert{}\sum_{l} v_{t,l} + \sum_{l} u_{t,l}\right\Vert{}}$$



### 2. Инкрементальная онлайн-кластеризация и память

Центроиды $c_k$ обновляются по мере генерации каждого токена с адаптивным порогом создания новых кластеров $\delta$. Для исключения квадратичной сложности по памяти векторы $\pi_t$ не сохраняются целиком — статистика сжимается в логарифмические гистограммы расстояний $b_i = b_0 \cdot r^i$ объёмом $O(K \cdot B)$, где число бинов масштабируется как $B = \lceil B_0 N^{1/3} \sqrt{K} \rceil$.

### 3. Метрика пути и относительное доминирование

* **Накопленная масса весов:** $S_t = \sum_{s \le t} \sum_k w_{s,k}$.
* **Симметричная матрица расстояний между кластерами:**

$$d_{\text{path}}(i, j) = \max\Big(0,\; \vert{}S(\mu_i) - S(\mu_j)\vert{} - \beta(\sigma_i + \sigma_j)\Big)$$


* **Адаптивный порог активности:** $\theta_t = k_{\text{model}} \cdot S_t$.
* **Доминирующий кластер $k^*(t)$:** определяется максимумом нормированной локальной поддержки среди соседей по графу с динамическим fallback-маскированием.

### 4. Топология симплициального комплекса

Из очищенного ядра порядка $E_{\text{core}} = E \setminus \{e : \text{частота}(e) < \phi\}$ строится комплекс $K(E_{\text{core}})$:

* **0-симплексы:** уникальные направленные переходы ядра.
* **1-симплексы:** связные пары переходов $(e_i, e_{i+1})$, где конец первого совпадает с началом второго.
* **2-симплексы:** связные тройки последовательных шагов $(e_i, e_{i+1}, e_{i+2})$.
* **Эйлерова характеристика:** $\chi = \vert{}K^{(0)}\vert{} - \vert{}K^{(1)}\vert{} + \vert{}K^{(2)}\vert{}$.

### 5. Гомеоморфизм и динамическая устойчивость

* **Максимальный общий подкомплекс:** $K^* = K_1 \cap K_2$.
* **Индикатор попарного гомеоморфизма:**

$$\text{Stab}_{\text{top}} = \mathbb{1}\left[\vert{}K^*\vert{} \ge \rho(T_{\min}) \cdot \min(\vert{}K_1\vert{}, \vert{}K_2\vert{})\right], \quad \rho(T_{\min}) = \rho_{\min} + (\rho_{\max} - \rho_{\min}) \frac{T_{\min}}{T_{\min} + T_0}$$


* **Накопленная устойчивость $\Sigma(h)$:** экспоненциальное сглаживание с адаптивной памятью $\alpha_h$. Срыв режима рассуждения фиксируется при $\Sigma(h) - \Sigma(h-1) < -\tau_h$.

## 📂 Структура репозитория

Архитектура организована в виде модульной системы из 25 компонентов:

```text
├── config.yaml               # Базовая конфигурация параметров и гиперпараметров
├── requirements.txt          # Зависимости окружения (PyTorch, Transformers, Datasets)
├── main.py                   # CLI точка входа для запуска экспериментов
│
├── core/                     # Вычислительное ядро пространства представлений
│   ├── __init__.py
│   ├── representations.py    # Экстрактор направлений v, u, pi_t и контейнер ActData
│   ├── metrics.py            # Метрики пути d_path, центры mu, накопленные суммы S_t
│   ├── dominance.py          # Пороги theta_t, множество активных A_t, доминирование k*(t)
│   └── clustering.py         # OnlineKMeans, log-гистограммы, петля K_0 <-> delta
│
├── graph/                    # Построение графов переходов и выделение порядка
│   ├── __init__.py
│   ├── transitions.py        # Дискретные ребра e_t, отсечение fallback-шагов
│   ├── matrix.py             # Матрица частот M_ij и стохастическая матрица P_trans
│   └── core_order.py         # Фильтрация частотного шума phi, сборка E_core
│
├── topology/                 # Топологический анализ и симплициальные инварианты
│   ├── __init__.py
│   ├── complex.py            # Триангуляция K(E_core), 0/1/2-симплексы, эйлерова характеристика
│   ├── homomorphism.py       # Поиск K* = K1 ∩ K2, адаптивный rho(T_min), индикатор Stab_top
│   └── stability.py          # Накопленная устойчивость Sigma(h), порог tau_h, детекция срывов
│
├── calibration/              # Иерархическая многоуровневая калибровка
│   ├── __init__.py
│   ├── groups.py             # Структурирование параметров (группы A, B, C1-C3, D, E)
│   ├── criteria.py           # Функционалы качества (структура, SNR, невязка окна/связности)
│   └── hierarchy.py          # Пошаговый пайплайн A -> B -> C -> D -> E с контролем деградации
│
└── experiment/               # Слой интеграции, инференса и бенчмаркинга
    ├── __init__.py
    ├── dataset.py            # Загрузка и стандартизация HumanEval и MBPP
    ├── model.py              # Обёртка CoderModel над causal LLM (выгрузка hidden_states)
    ├── pipeline.py           # GenerationPipeline: авторегрессия + онлайн-анализ
    ├── evaluator.py          # Изолированный runner проверочных assert-тестов (pass@1)
    └── runner.py             # Главный оркестратор ExperimentRunner, агрегация и экспорт в JSON

```

## ⚙️ Уровни иерархической калибровки

Калибровка исключает перекрестное искажение параметров за счет изолированной пошаговой настройки:

| Уровень | Группа | Параметры | Целевой критерий |
| --- | --- | --- | --- |
| **Уровень 1** | **A** | `k_model`, `phi` | Максимизация топологической воспроизводимости графа на разбиении $\mathcal{H}_1 / \mathcal{H}_2$. |
| **Уровень 1'** | **B** | `rho_min`, `rho_max`, `T_0`, `tau_min`, `tau_max` | Максимизация отношения сигнал/шум (SNR) при различении гомеоморфизмов. |
| **Уровень 1'** | **C1** | `alpha_min`, `alpha_max`, `n_0_alpha` | Оптимизация окна памяти адаптивного сглаживания устойчивости. |
| **Уровень 1'** | **C2** | `beta_K_0`, `alpha_0`, `h_0`, `delta_h_0`, `gamma_h` | Балансировка темпа расширения словаря кластеров. |
| **Уровень 1'** | **C3a** | `lambda_reg`, `n_iter`, `step` | Минимизация невязки в замкнутой петле оптимизации $K_0 \leftrightarrow \delta$. |
| **Уровень 1'** | **C3b** | `b_0`, `r`, `B_0`, `B_max` | Точность интерполяции квантилей логарифмических гистограмм. |
| **Уровень 2** | **D** | `n_0` | Минимизация взвешенной невязки динамического радиуса окна $W_t$ и порога $S_t$. |
| **Уровень 3** | **E** | `beta` | Минимизация рассогласования средней связности графа и радиуса окна. |

## 🚀 Установка и запуск

### Требования

* Python 3.10+
* Операционная система: Linux, macOS или Windows (с поддержкой `multiprocessing`)
* Доступ к Hugging Face Hub (для автоматической загрузки весов модели и датасетов)

### 1. Клонирование и окружение

```bash
git clone https://github.com/bibishaki/rre-reasoning-regimes.git
cd rre-reasoning-regimes

python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt

```

### 2. Быстрый запуск (Smoke Test)

Прогон 5 задач HumanEval без предварительной калибровки:

```bash
python main.py --tasks 5 --output quick_test.json

```

### 3. Полный исследовательский цикл с калибровкой

Запуск автоматической многоуровневой калибровки на первых 6 задачах и тестирование оставшегося пула с сохранением полного аналитического отчета:

```bash
python main.py --calibrate --calib-samples 6 --tasks 50 --output final_report.json

```

### 4. Параметры командной строки

* `--config` *(str)*: Путь к файлу конфигурации (по умолчанию: `config.yaml`).
* `--calibrate` *(flag)*: Запустить иерархический пайплайн калибровки $A \to E$ перед генерацией.
* `--calib-samples` *(int)*: Количество эталонных задач для калибровочного этапа (по умолчанию: 6).
* `--tasks` *(int)*: Ограничить количество задач из датасета (переопределяет значение из конфигурации).
* `--output` *(str)*: Путь для сохранения результирующего отчёта JSON (по умолчанию: `results.json`).

## 🛠️ Зависимости стек-технологий

* **PyTorch (`torch`):** Тензорные вычисления на CPU в `float32`, геометрические операции над расстояниями.
* **Hugging Face (`transformers`, `datasets`):** Архитектура `Qwen/Qwen2.5-Coder-0.5B`, извлечение `hidden_states`, доступ к бенчмаркам `openai_humaneval` и `mbpp`.
* **NumPy / SciPy:** Линейная интерполяция, квантильный анализ гистограмм, оптимизация невязок.
* **PyYAML:** Парсинг и валидация конфигурационных файлов.
* **Multiprocessing:** Изолированная среда выполнения программного кода с принудительным завершением зависших процессов по тайм-ауту.
